## 2. Architecture

```
daemon startup
  ├─ Manager.Start(ctx, cfg)           ← reads ~/.tether/config.json [mcp.servers]
  │   └─ go-sdk stdio MCP client sessions (one Supervisor goroutine per server)
  ├─ build singleton *mcp.Server       ← tools populated from gateway.ListToolsSnapshot()
  │   └─ (re-registration on Supervisor reconnect calls srv.AddTool / srv.RemoveTools)
  ├─ InjectMCPServer(mcpPort)          ← writes ~/.claude/settings.json (fatal on failure)
  └─ HTTP loopback 127.0.0.1:<mcpPort> (default 8899)
       └─ POST /mcp
            └─ mcp.StreamableHTTPHandler(getServer=func(){return singleton}, opts)

daemon shutdown (ordered)
  ├─ 1. loopback.Stop(drainCtx)        ← stop accepting new sessions; drain up to 5s
  ├─ 2. mcpManager.StopAll()           ← close stdio children
  └─ 3. RemoveMCPServer()              ← housekeeping for next CC session start
```

`RemoveMCPServer` is called last because CC does not hot-reload `settings.json` — the entry
is only relevant to the next CC process start, not the running one. In-flight requests are
handled by the drain window in step 1.

**Crash recovery:** if the daemon crashes without reaching `RemoveMCPServer`, a stale
`mcpServers.tether` entry persists in `settings.json`. The NEXT daemon start calls
`InjectMCPServer` which unconditionally removes any `_tether_managed` entry before
writing the fresh one — same recovery path as the existing `PreToolUse` hook entry.

## 3. Components

### 3.1 HTTP loopback — `internal/server/mcp_loopback.go` (new)

A standalone `net/http.Server` bound to `127.0.0.1:<mcpPort>` (default 8899,
configurable via `--mcp-port` flag).

```go
type MCPLoopback struct {
    srv      *http.Server
    mcpSrv   *mcp.Server  // singleton, built once at construction
}

func NewMCPLoopback(port int, mcpSrv *mcp.Server) *MCPLoopback
func (l *MCPLoopback) Start(ctx context.Context) error
func (l *MCPLoopback) Stop(drainCtx context.Context) error
```

**Singleton server pattern:**

```go
// BuildMCPServer constructs the singleton *mcp.Server, wiring gateway proxies
// and builtin tools. Called once at daemon startup after Manager.Start().
func BuildMCPServer(gw *gateway.Gateway, bi *builtin.Registry) *mcp.Server {
    srv := mcp.NewServer(&mcp.Implementation{Name: "tether", Version: "v0.3.1"}, nil)
    for _, e := range gw.ListToolsSnapshot() {
        entry := e // capture
        srv.AddTool(&entry.Tool, func(ctx context.Context, req *mcp.CallToolRequest) (*mcp.CallToolResult, error) {
            return gw.CallTool(ctx, gateway.CallRequest{
                ToolName:  entry.PrefixedName,
                Arguments: req.Params.Arguments, // json.RawMessage, passed verbatim
            })
        })
    }
    bi.RegisterInto(srv)
    return srv
}
```

`getServer` simply returns this singleton — all CC connections share the same `*mcp.Server`
instance, which is what the go-sdk `NewStreamableHTTPHandler` doc explicitly allows and
expects for stateful servers. When a Supervisor reconnects a crashed child and re-registers
tools, it calls `srv.AddTool` / `srv.RemoveTools` directly; all connected sessions receive
a `notifications/tools/list_changed` automatically (go-sdk behaviour).

**Handler options:**
```go
mcp.NewStreamableHTTPHandler(func(_ *http.Request) *mcp.Server { return singleton },
    &mcp.StreamableHTTPOptions{
        SessionTimeout:             30 * time.Minute,
        DisableLocalhostProtection: false, // enforce loopback Host header
    })
```

**Security — loopback plain HTTP threat model:**

The loopback `127.0.0.1` binding is the primary boundary. `DisableLocalhostProtection:
false` (the default) means go-sdk v1.6.0 rejects requests with a non-loopback `Host`
header, closing the browser/DNS-rebinding vector.

Remaining exposure: any process running under the **same OS UID** on the host can reach
the port. On the user's remote Linux container (shared infra) this is a real threat.

**v0.3.1 mitigation:** inject a per-daemon bearer token into `settings.json` and validate
it in `MCPLoopback.ServeHTTP` before passing to the SDK handler.

```go
// At daemon startup: generate a random 32-byte token, write to ~/.tether/mcp-token (0600).
// InjectMCPServer includes it in the settings.json headers entry.
// MCPLoopback strips and validates the Authorization: Bearer <token> header before
// passing to the SDK handler.
{
  "mcpServers": {
    "tether": {
      "type": "http",
      "url": "http://127.0.0.1:8899/mcp",
      "headers": {"Authorization": "Bearer <token>"},
      "_tether_managed": true
    }
  }
}
```

Token written to `~/.tether/mcp-token` (0600) at daemon start; deleted on clean shutdown;
regenerated on next start (stale file → overwrite). This closes the same-UID-process vector
without requiring TLS.

### 3.2 Builtin tools — `internal/mcp/builtin/workspace.go` (new package)

```go
type Registry struct {
    root string // resolved via filepath.EvalSymlinks at construction
}

func New(workspaceRoot string) (*Registry, error) // returns error if EvalSymlinks fails
func (r *Registry) RegisterInto(srv *mcp.Server)
```

**Tools:**

| Tool | Input | Output |
|---|---|---|
| `workspace_read_file` | `{"path": string}` | File content as text |
| `workspace_list_files` | `{"dir": string}` (optional, default `.`) | `[{"name": string, "is_dir": bool}]` |

**Path safety (all four cases must be covered by tests):**

```go
func (r *Registry) safeJoin(input string) (string, error) {
    joined := filepath.Join(r.root, input)
    resolved, err := filepath.EvalSymlinks(joined)
    if err != nil {
        return "", err // file not found OR symlink escapes to non-existent target
    }
    // Use separator-suffixed root to prevent /tmp/ws matching /tmp/ws-evil/
    if !strings.HasPrefix(resolved, r.root+string(os.PathSeparator)) &&
        resolved != r.root {
        return "", fmt.Errorf("path escapes workspace")
    }
    return resolved, nil
}
```

Tests must cover:
1. `../../../etc/passwd` — path traversal
2. `/etc/passwd` — absolute path input
3. Symlink inside workspace pointing outside (e.g. `ln -s /etc/passwd ws/inside.txt`)
4. `/var/...` vs `/private/var/...` on macOS (EvalSymlinks resolves `/var` → `/private/var`)

Return MCP error **result** (not Go error) on path violations — the LLM reads the message.

### 3.3 CC settings injection — `internal/agent/cc_settings.go` additions

Two new functions following the existing `InjectPermHook` / `RemovePermHook` atomic-rename
pattern:

```go
// InjectMCPServer writes mcpServers.tether to ~/.claude/settings.json.
// It first removes any existing _tether_managed mcpServers entry (idempotent).
// Token is the per-daemon bearer token from ~/.tether/mcp-token.
func InjectMCPServer(port int, token string) error

// RemoveMCPServer removes the tether-managed mcpServers.tether entry.
func RemoveMCPServer() error
```

`InjectMCPServer` failure is **fatal** — the daemon is unusable if CC cannot discover
tether's tools. Use `--skip-mcp-inject` flag to bypass in tests / CI.

### 3.4 Gateway interface changes — `internal/mcp/gateway/gateway.go`

`CallRequest.Arguments` changes from `map[string]any` to `json.RawMessage`:

```go
type CallRequest struct {
    SessionID string
    ToolName  string
    Arguments json.RawMessage  // was map[string]any
}
```

**Why this is safe:** On the receive side, `mcp.CallToolRequest.Params.Arguments` is
`json.RawMessage`. Forwarding verbatim to `liveConn.CallTool`, which passes through
`mcp.CallToolParams.Arguments` (typed `any`), causes `json.Marshal` to emit the raw bytes
verbatim — no double-encoding. This avoids an unmarshal+remarshal in the gateway hot path.

**Propagation:** `host.ServerConn.CallTool` signature must also change to accept
`json.RawMessage` (see §4 changelist). The `liveConn` and all test fakes must follow.

### 3.5 Gateway new method — `gateway.ListToolsSnapshot()`

```go
// ListToolsSnapshot returns a snapshot of all registered tools for mcp.Server construction.
// Safe to call concurrently — delegates to Registry.ListAll() which holds RLock.
func (g *Gateway) ListToolsSnapshot() []registry.ToolEntry {
    return g.reg.ListAll()
}
```

Called once at daemon startup (in `BuildMCPServer`). On Supervisor reconnect, the existing
`reg.Register` / `reg.Deregister` path calls `srv.AddTool` / `srv.RemoveTools` on the
singleton — `ListToolsSnapshot` is not called again.

### 3.6 Config source — resolved (was open question 1)

**Decision:** tether reads its own config from `~/.tether/config.json`; polyforge-coding
integration passes the workspace MCP config explicitly via `--mcp-config` flag.

```go
// Default config path: ~/.tether/config.json, [mcp.servers] section.
// Override: --mcp-config <path> (polyforge passes .workspace/config.json).
func loadMCPConfig(flagPath string) (*host.Config, error)
```

This decouples tether from the polyforge directory layout — end users of tether who do not
run polyforge can still configure MCP servers in `~/.tether/config.json`.

### 3.7 Manager wiring — daemon startup

```go
// 1. Load MCP config (tether-owned or --mcp-config override).
mcpCfg, err := loadMCPConfig(mcpConfigFlag) // fatal on parse error; empty config = ok
if err != nil { log.Fatalf("mcp config: %v", err) }

// 2. Start Manager (spawns stdio child processes).
mcpManager := host.NewManager(registry, histLogger)
if err := mcpManager.Start(ctx, mcpCfg); err != nil {
    log.Fatalf("mcp manager: %v", err)
}

// 3. Build singleton mcp.Server.
builtins, err := builtin.New(workspaceRoot)
if err != nil { log.Fatalf("builtin init: %v", err) }
gw := gateway.New(mcpManager, registry, permManager, histLogger)
mcpSrv := BuildMCPServer(gw, builtins)

// 4. Start loopback listener.
loopback := mcp_loopback.New(mcpPort, mcpSrv)
if err := loopback.Start(ctx); err != nil {
    log.Fatalf("mcp loopback: %v", err)
}

// 5. Generate bearer token and inject into CC settings (fatal on failure).
token := generateBearerToken()     // 32 random bytes, hex-encoded
_ = os.WriteFile(mcpTokenPath, []byte(token), 0o600)
if err := agent.InjectMCPServer(mcpPort, token); err != nil {
    log.Fatalf("mcp settings inject: %v", err)
}

// Shutdown (ordered):
// 1. Drain active MCP sessions (up to 5s).
drainCtx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
defer cancel()
loopback.Stop(drainCtx)
// 2. Close stdio children.
mcpManager.StopAll()
// 3. Housekeeping for next CC session.
_ = agent.RemoveMCPServer()
_ = os.Remove(mcpTokenPath)
```
